# ODM Suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace ODM's toolbar, sidebar and modal-first UI with the approved suite, including queue order and remaining size, while keeping every feature reachable.

**Architecture:** Decisions live in pure, tested functions in `app/src/lib/home.ts` and `app/src/lib/model.ts`. Components stay thin and reuse today's logic. The engine gains one command, `reorder_queue`.

**Tech Stack:** Svelte 5, TypeScript, Vitest, Tauri 2, Rust.

**Spec:** `docs/superpowers/specs/2026-11-02-odm-suite-design.md`. Mockups: `design/odm-suite/odm-suite.figcraft`. Frame numbers match the spec.

**Depends on:** `docs/superpowers/plans/2026-11-02-odm-extension-and-formats.md` Task 4, for `VideoOverride`.

## Global Constraints

- The user's installed ODM may be running downloads. Never start, stop, install or update it on Windows, and never run `pnpm tauri dev` there. Run the app and `odm-appcore` tests in WSL (`Ubuntu-22.04`) until the user says otherwise.
- Work on branch `feat/suite`. It ships as one release. Ask before any push.
- Tokens keep their `app.css` names. `--idle` is never text. Orange marks the next step only.
- Every current feature stays reachable. Window minimum stays 900 × 560.
- Checks: `cd app && pnpm test && pnpm check`, plus `cargo fmt --check` and `cargo clippy --workspace -- -D warnings` in WSL. For UI tasks, compare the running app in WSL with the named frames.

## Review Focus

1. **Reorder while rows change:** an id that finished or was removed mid-drag is skipped, and the rest keep their order. Task 3 test.
2. **Unknown sizes:** a queue with no known size shows "2 unknown left", not "0 B left". Task 4 test.
3. **Ctrl+V with non-link text:** nothing opens, and nothing is lost in a text field. Task 8 test.
4. **Old section links:** the tray's `general` or `speed` section still opens the right page. Task 13 test.
5. **Unknown error code:** a future code shows "The download stopped" with the raw message under Technical details. Task 10 test.
